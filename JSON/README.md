- Json = Javascript Object Notation
- Json là một định dạng văn bản có cấu trúc dữ liệu dùng để biểu diễn và trao đổi dữ liệu


JavaScript Object
   ↓
JSON.stringify()
   ↓
JSON String
   ↓
gửi qua HTTP / lưu file / API
   ↓
JSON String
   ↓
JSON.parse()
   ↓
JavaScript Object


- JSON chứa được các kiểu dữ liệu sau:
+ string / number / boolean / null / object / array

- Dạng JSON Object : key phải nằm trong ''
